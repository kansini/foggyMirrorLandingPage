# 雾镜 · Foggy Mirror

雾镜 App 的中英双语响应式落地页，使用 Vue 3、TypeScript、Sass、GSAP 和 WebGL 2。所有图片均为项目本地素材，无远程字体或图片依赖。

页面以「呼——雾里见」为主题：整个首屏是一面可擦画的雾镜，导航与文字悬浮在玻璃上。向下滚动时，整面雾镜收拢到真实 App 截屏中，继续进入可浏览的功能截屏展。下方为镜面风格展示，以及「照片留住结果，视频留住过程」的雾迹展示。中文和英文有各自的字体比例与断行规则。

## 雾镜与动画

- 首屏支持鼠标拖动擦雾、一键画心、清雾，以及向四周扩散的起雾动画。
- 手机默认允许纵向滚动；点击画笔进入触屏绘画，再次点击结束绘画并恢复滚动。
- GSAP 驱动文字从雾中显现、渐进画心、起雾扩散、整屏镜面向手机收拢、截屏横向叙事、镜面视差与 15 秒逐笔擦雾演示。
- 固定滚动叙事仅在宽高足够的桌面启用。移动端使用原生横向滑动截屏，系统「减少动态效果」偏好下保留静态布局。
- 雾镜参照 iOS 的 `FogRenderer.swift`、`FogShaders.metal.txt` 与 `StrokeWaterSimulation.swift`：对清晰示例照片做两遍可分离高斯模糊，保留原始明暗；双尺度不规则凝露参与折射、方向性高光与暗侧弯月面计算。
- 笔迹通过连续变宽胶囊写入 GPU 擦除场，边缘柔化并带克制的湿润高光；有限数量的笔迹水痕按重力、黏滞与停滞演化。起雾按稳定噪声前沿积累雾量，并渐渐覆盖旧笔迹。
- 擦除与雾量场在支持时使用半浮点纹理，改变窗口大小时在 GPU 上重采样保留历史。限制像素预算；镜面离屏、切入手机收拢阶段或页面进入后台时暂停绘制。
- header 固定在视口顶部，背景层铺满页面宽度，导航内容保持居中。首屏透明、无背景模糊；hero 收拢完成或自然离开首屏后，再淡入 `backdrop-filter: blur(10px) saturate(110%)`（含 WebKit 前缀），并随明暗主题调整颜色。雾气密度与模糊柔度统一在渲染器中配置。

## 照片与视频展示

- 用真实 App 照片预览中的作品替代原先的渐变色明信片，保留凝露与擦写质感。中英文采用各自的截屏。
- 视频特性通过 15 秒网页演示呈现：与首屏复用同一光学渲染器，爱心、手写字和笑脸逐笔擦开雾层。演示标注「网页模拟」，并非 App 录屏或网页录制功能。
- GSAP 控制时间、播放、暂停与重播。离屏与后台暂停；减少动态效果时展示完成画面；WebGL 不可用时展示真实 App 作品。
- 明确介绍 App 的最长 15 秒无声视频、保存到雾迹或相册以及系统分享能力。

## 语言与主题

页头可随时切换中文／英文、浅色／深色。双语覆盖正文、FAQ、弹窗、图片说明和无障碍标签，同时更新页面标题、描述和 `html lang`。

手动切换主题时使用「哈一口夜色」：按钮里的图标先隐入薄雾，再从按钮位置以柔化边缘揭开新主题，银蓝夜雾或暖白晨雾随后散去，时长约 0.9 秒。支持 View Transitions 的浏览器使用羽化遮罩，较旧浏览器使用雾气与主题色渐变；减少动态效果时仅淡入。首屏配合一次短暂的光学雾量变化，不修改擦除场、不清除笔迹、不改变滚动位置。

首次打开时主题跟随系统；手动切换后保存选择。语言默认中文。偏好仅保存在当前浏览器的 `localStorage` 中（`foggy-mirror-language`、`foggy-mirror-theme`），存储不可用时仍可在当前页面切换。主题在页面加载的早期初始化，减少明暗闪烁。

## 本地开发

```sh
npm run dev
```

## 类型检查与生产构建

```sh
npm run build
```

构建命令依次执行 `vue-tsc -b` 和 `vite build`，静态产物位于 `dist/`。GLSL 会在浏览器创建 WebGL 2 管线时编译与链接，失败时退回静态示例照片。按项目验证约定，仅执行类型、着色器编译与构建检查，不运行功能、离屏渲染、浏览器 UI 或性能测试。

## 文件与内容

- `src/App.vue`：页面结构、文案、镜面风格、FAQ、隐私说明、App 实际界面预览与 App Store 链接。
- `src/components/AppShowcase.vue`：桌面滚动截屏展、移动端横向浏览与截屏预览入口。
- `src/components/ThemeMist.vue`：主题切换的起雾、羽化扩散、按钮动效与兼容处理。
- `src/components/MistMemories.vue`：真实作品照片、逐笔擦雾演示、播放控件与视频录制功能介绍。
- `src/screenshots.ts`：双语截屏路径映射。
- `src/content.ts`：中英文文案与共享内容类型。
- `src/composables/usePreferences.ts`：语言、主题、偏好保存、系统主题同步与元信息更新。
- `src/components/FogMirror.vue`：整屏擦雾、画心、清雾与扩散起雾的交互。使用本地清晰示例照片，不调用相机或麦克风，不上传笔迹。
- `src/rendering/WebGLFogRenderer.ts`：场景纹理、高斯模糊、擦除与凝结场、有限水痕演化、绘制调度与 GPU 资源管理。
- `src/rendering/shaders/`：参照 iOS 光学处理移植的 GLSL 着色器，包括最终合成、模糊、连续笔刷与起雾沉积。
- `src/components/AppIcon.vue`：统一的 SVG 图标。
- `src/styles/main.scss`：明暗主题变量、组件样式、双语排版及桌面、平板、手机布局。
- `src/styles/immersion.scss`：整屏镜面、悬浮界面、镜面收拢与双语首屏布局。
- `public/images/`：来自雾镜现有品牌与营销资料的插画、橘猫图片与真实 App 界面。照片示例中的作品取自 App 截屏，动态绘画展示为网页模拟。
- `index.html`：页面标题、中文描述与分享元信息。

动画尊重系统「减少动态效果」偏好；原生 FAQ 与对话框支持键盘操作。
