# 雾镜 · Foggy Mirror

雾镜 App 的中英双语响应式落地页，使用 Vue 3、TypeScript、Sass、GSAP 和 Canvas 2D。所有图片均为项目本地素材，无远程字体或图片依赖。

页面以「呼——雾里见」为主题：整个首屏是一面可擦画的雾镜，导航与文字悬浮在玻璃上。向下滚动时，整面雾镜收拢到真实 App 截屏中，继续进入可浏览的功能截屏展。下方为心情气象台与错落的心情明信片。中文和英文有各自的字体比例与断行规则。

## 雾镜与动画

- 首屏支持鼠标拖动擦雾、一键画心、清雾，以及向四周扩散的起雾动画。
- 手机默认允许纵向滚动；点击画笔进入触屏绘画，再次点击结束绘画并恢复滚动。
- GSAP 驱动文字从雾中显现、渐进画心、起雾扩散、整屏镜面向手机收拢、截屏横向叙事、镜面视差、明信片展开与 SVG 笔迹动画。
- 固定滚动叙事仅在宽高足够的桌面启用。移动端使用原生横向滑动截屏，系统「减少动态效果」偏好下保留静态布局。
- 画布缓存凝露纹理，限制像素预算，并在主题切换或窗口变化后保留归一化笔迹。

## App 截屏

原始文件为 `src/assets/screenshots/cn/01.png` 至 `05.png` 和 `en/01.png` 至 `05.png`，按启动、绘画、收藏、分享、风格顺序展示。网页使用 `public/images/screenshots/` 中的 WebP 派生文件，原始 PNG 保留不变。截屏展、首屏手机与放大预览随语言切换到对应素材。

## 语言与主题

页头可随时切换中文／英文、浅色／深色。双语覆盖正文、FAQ、弹窗、图片说明和无障碍标签，同时更新页面标题、描述和 `html lang`。

首次打开时主题跟随系统；手动切换后保存选择。语言默认中文。偏好仅保存在当前浏览器的 `localStorage` 中（`foggy-mirror-language`、`foggy-mirror-theme`），存储不可用时仍可在当前页面切换。主题在页面加载的早期初始化，减少明暗闪烁。

## 本地开发

```sh
npm run dev
```

## 类型检查与生产构建

```sh
npm run build
```

构建命令依次执行 `vue-tsc -b` 和 `vite build`，静态产物位于 `dist/`。按项目验证约定，仅执行类型与构建检查，不运行功能、浏览器 UI 或性能测试。

## 文件与内容

- `src/App.vue`：页面结构、文案、镜面风格、FAQ、隐私说明、App 实际界面预览与 App Store 链接。
- `src/components/AppShowcase.vue`：桌面滚动截屏展、移动端横向浏览与截屏预览入口。
- `src/screenshots.ts`：双语截屏路径映射。
- `src/content.ts`：中英文文案与共享内容类型。
- `src/composables/usePreferences.ts`：语言、主题、偏好保存、系统主题同步与元信息更新。
- `src/components/FogMirror.vue`：整屏擦雾、画心、清雾与扩散起雾。使用本地品牌插画，不调用相机或麦克风，不上传笔迹。
- `src/components/AppIcon.vue`：统一的 SVG 图标。
- `src/styles/main.scss`：明暗主题变量、组件样式、双语排版及桌面、平板、手机布局。
- `src/styles/immersion.scss`：整屏镜面、悬浮界面、镜面收拢与双语首屏布局。
- `public/images/`：来自雾镜现有品牌与营销资料的插画、橘猫图片与真实 App 界面。照片背景上的手写内容为创意场景示意。
- `index.html`：页面标题、中文描述与分享元信息。

动画尊重系统「减少动态效果」偏好；原生 FAQ 与对话框支持键盘操作。
